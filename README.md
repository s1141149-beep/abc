# WWII Beach Assault

二次大戰海灘登陸主題的 2D 橫向射擊街機遊戲。

---

## 操作說明

| 按鍵 | 功能 |
|------|------|
| ← → | 左右移動 |
| ↑ | 跳躍 |
| ↓ | 蹲下 |
| 滑鼠 | 瞄準 |
| 左鍵 | 射擊 |
| 1-4 | 切換武器 |
| R | 填彈 |
| 空白鍵 | 開始遊戲 / 重新開始 |

|------|---------|------|------|

## 遊戲系統

### 波次系統
- 每波擊殺指定數量敵人後進入下一波
- 波次越高，敵人數量越多、強度越強

### COMBO 連擊系統
- 短時間內連續擊殺敵人可累積連擊
- 連擊倍率影響分數加成（最高10倍）
- 每5連擊顯示特殊提示

### 彈藥拾取
- 擊殺敵人隨機掉落彈藥箱
- 拾取可補充步槍/散彈槍/機槍彈藥

### 浮動文字
- 擊殺敵人顯示獲得分數
- COMBO 連擊顯示倍率和提示
